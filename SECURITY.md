# Security policy

## Private reporting

Report suspected vulnerabilities, exposed credentials, or unintended
sensitive data through
[GitHub private vulnerability reporting](https://github.com/NewAsiaSuperbear/conditional-fiber-geometry/security/advisories/new).
Please include the affected revision and enough information to reproduce or
locate the issue without placing the sensitive value in a public channel.

Do not open a public issue that contains a token, private key, password,
personal record, machine identifier, or other confidential material. Do not
create or transmit a live secret solely to demonstrate a report.

## Scope

Security reports cover the current default branch and public release
artifacts. Mathematical objections, non-sensitive numerical discrepancies,
and ordinary build failures should use the public issue tracker instead.

The repository is research software and is provided without warranty under
the applicable licenses. A private report may lead to removal of an artifact,
credential rotation by its owner, a corrected release, or a history rewrite
when required.
