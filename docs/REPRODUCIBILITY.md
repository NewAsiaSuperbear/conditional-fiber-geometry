# Reproducibility

This repository supports three forms of verification: self-contained software
and analytic checks; regeneration of figures and derived numerical summaries
from committed numeric inputs; and direct inspection of historical sanitized
EIT tables. The historical input tables are not regenerated by the plotting
script. The complete finite-element EIT simulation is not included because its
source dataset and generator are not distributed in this release.

## Software requirements

The Python package requires Python 3.11 or later. The public release was
validated with the following environment:

| Component | Version |
|---|---:|
| Python | 3.12.13 |
| NumPy | 2.2.6 |
| Matplotlib | 3.10.3 |
| pytest | 8.4.1 |
| latexmk | 4.83 |
| pdfTeX | 3.141592653-2.6-1.40.25 |
| TeX distribution | TeX Live 2023/Debian |

The package metadata specifies supported dependency ranges. The exact table
above records the environment used for release validation, and
[`requirements-release.txt`](../requirements-release.txt) records the complete
Python dependency snapshot used for byte-level figure verification. Other
versions within the declared ranges may also work, but generated PDF bytes can
differ across Matplotlib or font-library versions even when their scientific
content is unchanged.

## Installation

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[test,figures]"
```

For the reference release environment, install the pinned Python dependencies
instead:

```bash
python -m pip install -r requirements-release.txt
python -m pip install --no-deps -e .
```

On Windows, activate the virtual environment with the platform-appropriate
command before installing the package.

## Correctness tests

Run the full test suite with:

```bash
python -m pytest -q
```

The tests cover the pseudoinverse derivative, derivative bounds, horizontal
transport, scaled projections, critical rank collapse, and the full-spectrum
covering expression. Mathematical regression tests also record two necessary
cautions:

- a derivative bound on disconnected components is not a global Lipschitz
  bound between those components; and
- ambient submersion alone does not exclude a non-neat, boundary-tangent
  level set.

Passing these tests checks implementations and representative identities. It
does not prove the manuscript's analytic theorems or verify Assumption Q for
the complete EIT parameter class.

## Deterministic analytic examples

Run:

```bash
python experiments/run_toy_validation.py
```

The script writes no files. It reports:

- the exact horizontal velocity for a scaled linear projection;
- the observation residual after Runge--Kutta transport on a parabolic level
  set;
- growth of the horizontal-lift norm near a critical point; and
- a representative full-spectrum logarithmic covering bound.

The script is deterministic and uses no random seed.

## Public numerical results

The directory [`experiments/results/`](../experiments/results/) contains
sanitized outputs from the completed EIT mechanism studies. The public files
contain scientific parameters, metrics, numeric point clouds, and plots; they
do not contain raw experiment-tracking databases or machine-specific artifact
locations.

The recorded generation seed for the fixed synthetic population used by the
principal local studies is `20260901`. This is distinct from the following
study-level seeds: whitening `20260902`, direct fiber `20260903`, and principal
spectral validation `20260904`. The population step cannot be replayed from
this release because its generator and full dataset are not bundled. The
principal study's main parameters were:

| Parameter | Value |
|---|---:|
| Base polygons | 10 |
| Replication points per fiber | 24 |
| Independent full-space starts | 96 |
| Fiber radius | 0.008 |
| Central-difference step | 0.002 |
| Relative numerical-rank threshold | 0.001 |
| Candidate masks | 800 |
| Cover repetitions | 8 |

The earlier direct-fiber and whitening studies use their own parameter files
within the corresponding result directories. The approximately `297.3`
amplification in the direct-fiber study and `402.7` in the later
spectral-validation study are independent experiments, not duplicate
estimates for one pair of masks.

The acceptance table reports 1,104 accepted starts out of 1,208 attempts, plus
34 base points. Its 1,138 rank checks therefore concern accepted/base points.
All 104 rejections came from one near-boundary polygon; its base diagnostics
are retained, but the historical run did not preserve rejected candidate
points, spectra, or admissibility margins.

The image-rank audit uses three separate archived Jacobian populations (seeds
`20260828`--`20260830`, 120 samples each). All 360 complete-data Jacobians have
thresholded numerical rank 8 at the declared relative threshold `0.001`. This
reproduces a finite-difference negative result--the refined image exponent is
not smaller than `8 - r` on these samples--rather than verifying a global rank
hypothesis.

The learned-completion archive uses network seeds `20260911`--`20260913`, 400
held-out polygons, one selected plus 20 score-trimmed random equal-budget
controls, and four
noise levels. Evaluation/sampling used seed `20260921`; the public analysis
uses 10,000 crossed seed--polygon bootstrap draws with seed `20261001`.

The finite-cloud covering archive contains 48 masks, 360 points per cloud, and
eight scales. The declared usable-scale criterion is
`0.1*n < median_cover_count < 0.9*n`; four scales pass it. Their mean Spearman
correlations are `0.990371` for the full-spectrum predictor and `0.853856` for
the smallest-singular-value surrogate. Saturated-mask counts across the eight
scales are `21, 13, 6, 4, 2, 1, 0, 0` out of 48.

## Regenerating figures and derived summaries

Regenerate the per-scale covering diagnostics from the committed historical
linear-cover table with:

```bash
python experiments/analyze_spectral_cover.py
```

This writes:

```text
experiments/results/spectral_validation/cover_scale_diagnostics.csv
experiments/results/spectral_validation/cover_scale_summary.json
```

Regenerate the public validation figure from its four committed CSV inputs
with:

```bash
python experiments/plot_spectral_validation.py
```

The script reads only `experiments/results/` and regenerates
`experiments/results/spectral_validation/conditional_geometry_validation.pdf`.
It does not create or modify any result table and does not rerun the EIT
forward solver. Additional outputs are documented in
[`experiments/README.md`](../experiments/README.md).

Regenerate the learned-completion JSON summary and, when Matplotlib is
installed, its PDF figure from the curated case-level NPZ with:

```bash
python experiments/analyze_learned_completion.py
```

The stable input/output contract is:

```text
experiments/results/learned_completion/per_case_metrics.npz
experiments/results/learned_completion/summary.json
experiments/results/learned_completion/learned_completion.pdf
```

The numerical analysis uses NumPy only. If Matplotlib is unavailable, the JSON
is still written and the optional PDF is skipped.

To verify the integrity of the committed result files, run:

```bash
cd experiments/results
sha256sum -c SHA256SUMS
```

The checksum of the generated PDF corresponds to the pinned release
environment above. With other supported plotting-library versions, compare the
displayed values and layout rather than expecting byte-identical PDF output.

If `sha256sum` is unavailable, compare the listed SHA-256 values with a local
platform-equivalent utility.

## What is and is not reproducible from this release

The following are self-contained:

- the Python test suite;
- the deterministic analytic examples;
- the mathematical regression cases;
- regeneration of the spectral-validation figure from committed CSVs;
- regeneration of the covering-scale CSV/JSON diagnostics from the committed
  historical linear-cover table;
- regeneration of the learned-completion summary and optional figure from the
  committed path-free NPZ;
- inspection of the continuation-acceptance and full-map-spectra tables;
- integrity verification of the committed numerical files; and
- compilation of the manuscript.

The following are not presently self-contained:

- generation of the complete synthetic EIT forward dataset;
- a full finite-element rerun of the mechanism experiments; and
- recomputation of the 360 complete-data Jacobians from forward solves;
- retraining the conditional EDM and U-Net models; and
- reproduction of historical experiment-tracking records.

The numerical archive should therefore be interpreted as a documented result
set supporting inspection and summary regeneration, not as a complete
end-to-end FEM workflow.

## Interpretation limits

- Finite-difference rank is a thresholded numerical diagnostic.
- A frozen-Jacobian corrector does not prove a continuum fiber theorem.
- PCA dimension on a finite cloud is an estimator, even when calibrated on
  known-dimensional samples.
- The thresholded rank-\(8\) experiment returned to the same numerical
  solution, consistent with local isolation; it
  did not estimate a zero-dimensional PCA cloud or establish global
  uniqueness.
- The mesh comparison covers three discretizations and does not establish a
  continuum FEM convergence rate.
- The numerical results do not verify boundary submersion or bidirectional
  no-exit over the complete polygon population.
- Rank stability is conditioned on accepted/base continuation points; rejected
  candidate points lack saved spectra and admissibility margins.
- The fact that all 360 sampled complete-data Jacobians have numerical rank 8
  does not prove exact or whole-fiber constant rank.
- The conditional EDM study is engineering evidence. The common six-channel
  budget, narrow 5.65--6.00 range of training-population mean numerical rank,
  lack of a controlled rank ablation, and use of EDM mean it does not test the
  external DDPM theorem or a learning gain from the `d-r` entropy refinement.

See the [experiment reuse and gap plan](EXPERIMENT_REUSE_AND_GAP_PLAN.md) for
the exact evidence-inclusion decisions and preregistered protocols needed to
address the remaining nonlinear-tube, horizontal-flow/coarea,
conditional-generation, and noisy-posterior gaps.
